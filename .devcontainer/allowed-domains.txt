# --- Docker Hub（DinD の dockerd が pull する先）---
# Testcontainers 契約テスト（postgres:17-alpine + Ryuk）と terraform MCP（docker run）の
# イメージ取得に必要。これが無いと `./gradlew check` の JDBC 契約テストが
# ContainerFetchException で落ちる。blob は AWS CloudFront（production.cloudfront.docker.com）
# 配信で、レジストリ API（registry-1.docker.io）とは別ホストなので両方許可する。
# CloudFront は IP がローテートするため、TTL 失効後に pull が timeout したら
# init-firewall.sh を貼り直して解決し直す（known-caveat）。
registry-1.docker.io
auth.docker.io
production.cloudfront.docker.com
